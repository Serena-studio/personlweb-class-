一点简单的自我介绍。

你好，我是 Serena，一名正在学习前端开发的学生。这个博客是我用来记录学习过程的地方。

为什么写博客

最直接的理由是——记性不好。很多东西当时看懂了，过两周再用就只剩「我好像学过」的模糊印象。 把理解过程写下来，既是给未来的自己留一份笔记，也是强迫自己把问题想清楚： 如果没法用简单的语言讲明白，通常说明还没真正懂。

这里会写什么

  • 前端学习笔记：HTML / CSS / JavaScript 的基础与进阶
  • 工具用法：Git、编辑器、命令行等提高效率的技巧
  • 踩坑记录：遇到并解决的问题，以及当时的排查思路
  • 生活随笔：偶尔写点与代码无关的东西

关于这个网站

纯静态站点，没有使用任何框架，所有页面都是手写的 HTML 和 CSS。 这样做的好处是简单、快、不需要构建步骤——改完文件刷新就能看到效果， 也方便直接托管在 GitHub Pages 上。

源码放在 GitHub， 如果发现内容有误，欢迎提 Issue 指正。

联系我

你可以通过 GitHub 找到我，或者发邮件到 example@example.com。看到都会回复，只是可能慢一点。
