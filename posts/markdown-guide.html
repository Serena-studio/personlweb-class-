Markdown 写作速查手册

2026 年 9 月 10 日 约 5 分钟 工具

Markdown 的语法简单到「五分钟就能学会」，但真到写的时候， 总有几个语法记不住——尤其是表格和嵌套列表。 这里把常用的整理出来，方便随时查阅。

标题

用 # 的数量表示层级，一到六级：

# 一级标题
## 二级标题
### 三级标题
#### 四级标题

建议一篇文章只用一个一级标题，其余从二级开始。 层级跳着用（比如二级直接接四级）虽然能渲染，但语义上不太规范。

强调

*斜体*  或  _斜体_
**粗体** 或  __粗体__
***粗斜体***
~~删除线~~

渲染效果：斜体、粗体、删除线。

列表

无序列表

- 苹果
- 香蕉
  - 香蕉的子类（缩进两个空格）
- 橙子

嵌套的关键是缩进两个空格，缩进不对就会变成同级。

有序列表

1. 第一步
2. 第二步
3. 第三步

任务列表

- [x] 已完成的任务
- [ ] 未完成的任务

链接与图片

[链接文字](https://example.com)
[带标题的链接](https://example.com "鼠标悬停显示")

![图片描述](https://example.com/img.png)

图片描述（alt 文本）最好写上。它对无障碍阅读有用， 图片加载失败时也能显示这段文字。

引用

> 这是一段引用。
>
> 可以有多行，也可以嵌套：
> > 嵌套的引用

渲染出来就是这样的效果，通常用来放摘录或补充说明。

代码

行内代码

用一个反引号包裹：git status。

代码块

用三个反引号包裹，并在开头指定语言以获得语法高亮：

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}
```

效果：

function greet(name) {
  return `Hello, ${name}!`;
}

如果代码里本身含有反引号，可以用四个反引号包裹外层。

表格

这是最容易写错的语法，注意第二行的分隔部分：

| 语言 | 类型 | 年份 |
| :--- | :--: | ---: |
| JavaScript | 动态 | 1995 |
| TypeScript | 静态 | 2012 |

第二行的冒号控制对齐方向：

  • :--- 左对齐（默认）
  • :--: 居中
  • ---: 右对齐

渲染结果：

语言类型年份
JavaScript动态1995
TypeScript静态2012

分割线

---
或
***
或
___

就是上面这条线。三种写法等价，选一个保持全文统一就行。

几个实用的细节

1. 换行

在 Markdown 里，单个回车不会产生换行，会被合并成一行。 要强制换行，可以在行末加两个空格， 或者直接空一行分段。

2. 转义特殊字符

如果想显示 *、# 这些符号本身而不是让它们生效， 在前面加反斜杠：\*、\#。

3. 写 URL 用尖括号

<https://example.com>

这样链接会自动识别，不需要额外的方括号。

小结

  • 日常写作用到的大概就这些：标题、列表、链接、代码、引用、表格
  • 表格和嵌套列表最容易写错，注意缩进和分隔行
  • 不确定效果时，写一段就预览一下，别攒到最后

熟练之后基本不用想，敲起来比用富文本编辑器点按钮快很多。
